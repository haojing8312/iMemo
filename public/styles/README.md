# Style Preview Images

This directory contains preview images for each photo generation style.

## Required Images

Please add the following image files (400x300px, JPEG format recommended):

1. `soft-pastel.jpg` - Soft pastel colors, dreamy baby photos
2. `natural-light.jpg` - Natural lighting, authentic style
3. `romantic-soft-focus.jpg` - Romantic soft focus for weddings
4. `vintage-film.jpg` - Vintage film grain effect
5. `documentary.jpg` - Documentary/photojournalistic style
6. `classic-portrait.jpg` - Classic formal portrait
7. `bright-colorful.jpg` - Bright vibrant colors for children
8. `cute-props.jpg` - Cute props and decorations
9. `playful-fun.jpg` - Playful energetic style
10. `warm-family.jpg` - Warm family atmosphere
11. `professional.jpg` - Professional business style
