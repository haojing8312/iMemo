- **状态**: 待评审

## 一、背景与目标

### 1.1 当前问题

1. **重复上传**：每次生成 AI 艺术照都需要重新上传照片，用户体验不佳
2. **命名局限**：当前叫"上传宝宝照片"，但产品支持全年龄段（婴儿、儿童、成人）
3. **照片丢失**：用户上传的照片仅用于单次生成，无法保存和复用

### 1.2 产品目标

1. **提升效率**：照片上传一次，永久保存，可重复使用
2. **全年龄支持**：去除"宝宝"限定，支持婴儿、儿童、青少年、成人等所有年龄段
3. **家庭友好**：支持多成员照片管理，适合全家使用
4. **隐私保护**：所有照片本地存储，符合产品定位

## 二、核心功能

### 2.1 照片库管理

#### 功能描述
用户可以上传照片到照片库，照片会永久保存在本地，可重复使用。

#### 核心能力
- ✅ 上传照片到照片库（支持多选）
- ✅ 查看所有照片（网格视图）
- ✅ 删除照片
- ✅ 照片详情查看（大图模式）

#### 界面结构
```
照片库页面
├── 顶部工具栏
│   ├── 标题："我的照片库"
│   └── [+ 添加照片] 按钮
├── 筛选排序区
│   ├── [按人物筛选] 下拉框（如有人物功能）
│   └── [排序方式] 下拉框（最新/最早）
└── 照片网格
    └── 照片卡片（4列）
        ├── 缩略图
        ├── 上传时间
        └── 操作按钮（查看/删除）
```

---

### 2.2 人物档案管理（可选，MVP 可暂缓）

#### 功能描述
为家庭成员创建人物档案，照片可关联到特定人物，方便管理和筛选。

#### 核心能力
- ✅ 创建人物（姓名、关系、生日）
- ✅ 编辑/删除人物
- ✅ 照片关联人物
- ✅ 按人物分组查看照片

#### 数据模型
```typescript
interface Person {
  id: string
  name: string              // 姓名，如"张小明"
  relationship?: string     // 关系：爸爸/妈妈/宝宝/爷爷/奶奶/其他
  birthDate?: string        // 生日，如"2024-02-15"
  avatar?: string           // 头像照片路径
  createdAt: number
}
```

### 2.3 照片选择流程重构

#### 当前流程
```
上传宝宝照片 → 选择里程碑 → 生成
```

#### 新流程
```
选择照片 → 选择场景主题 → 生成
    ↓
【照片来源】
├─ A. 从照片库选择（推荐）
│   ├─ 显示所有已保存照片
│   ├─ 支持按人物筛选（如有人物功能）
│   └─ 多选 1-5 张
└─ B. 临时上传新照片
    ├─ 用户选择本地照片
    ├─ 仅用于本次生成
    └─ 可选保存到照片库
```

#### 界面变化
**旧版**："上传宝宝照片"页面 → 直接上传

**新版**："选择照片"页面
- Tab 1: 从照片库选择（默认）
- Tab 2: 临时上传新照片

interface Photo {
  id: string

  originalName: string      // 原始文件名
  width: number
  height: number

  format: 'JPG' | 'PNG'

  // 新增字段
  personId?: string         // 关联的人物 ID（如有人物功能）

## 五、用户故事

### 故事 1：新用户首次使用

> **角色**：王女士，想为 8 个月大的宝宝生成百日照
>
> **流程**：
> 1. 打开应用，看到首页，点击"开始添加照片"
> 2. 上传 3 张宝宝照片到照片库
> 3. （可选）创建人物档案"王小宝"（关系：宝宝，生日：2024-02-15）
> 4. 点击"生成 AI 艺术照"
> 5. 在"选择照片"页，从照片库选择刚上传的 3 张照片
> 6. 在"选择场景主题"页，看到系统推荐"婴幼儿"分类，选择"百日照"
> 7. 选择"一键生成"，使用推荐风格
> 8. 等待生成，查看结果

**期望**：流程顺畅，照片保存到照片库，下次可复用

---

### 故事 2：老用户快速生成

> **角色**：李先生，照片库已有 50+ 张家庭照片
>
> **流程**：
> 1. 打开应用，点击顶部导航"生成艺术照"
> 2. 在"选择照片"页，从照片库快速选择 5 张妻子的照片
> 3. 选择场景"成人 - 情侣照"
> 4. 选择 3 种喜欢的风格
> 5. 生成完成，导出分享

**期望**：无需重复上传，从照片库快速选择，效率提升

---

### 故事 3：临时上传模式

> **角色**：张女士，临时想生成一张艺术照，但不想保存到照片库
>
> **流程**：
> 1. 点击"生成艺术照"
> 2. 在"选择照片"页，切换到"临时上传新照片" Tab
> 3. 上传 3 张照片，看到提示"临时上传的照片不会保存到照片库"
> 4. 继续生成流程
> 5. 生成完成后，临时照片自动清理

**期望**：支持临时模式，满足一次性需求
