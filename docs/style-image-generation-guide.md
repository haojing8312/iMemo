# HomeMemo 风格配图生成清单（中国面孔版）

**目标**: 使用 Google Imagen 3 (nano banana) 生成 11 张风格示例图片
**规格**: 所有图片统一 4:3 比例（800x600px）
**主题**: 展示不同摄影风格特点的人物肖像照片
**要求**: 图片风格要一目了然，让用户快速识别每种风格的视觉特征
**重要**: 所有模特必须是**中国人面孔**，符合中国用户审美

---

## 📐 统一规格参数

所有图片生成时使用以下基础参数：

- **比例**: `4:3` (横向)
- **分辨率**: 800x600px 或更高
- **主体**: 中国人物肖像（婴儿/儿童/成人/家庭场景）
- **面孔**: **East Asian features, Chinese appearance**（必须添加）
- **背景**: 简洁干净，突出风格特点
- **光线**: 根据风格调整，但保持专业摄影质感
- **构图**: 居中构图，人物占画面 40-60%

## 🛠️ 使用 nano banana (Google Imagen 3) 生成步骤

### **方法一：使用白底图 + img2img**

1. **准备底图**:
   ```
   使用: public/templates/white-base-4x3.png
   ```

2. **设置参数**:
   - Mode: **Image-to-Image**
   - Upload: `white-base-4x3.png`
   - Prompt: 复制对应风格的英文提示词
   - Strength: **0.85-0.95** (高强度重绘)
   - CFG Scale: **8-10**
   - Steps: **30-50**

3. **生成**:
   - 点击 Generate
   - 检查人物是否为中国面孔
   - 如不符合，在提示词开头强调 `Chinese person with East Asian features`

### **方法二：直接文生图**

如果 nano banana 支持直接文生图并指定比例：
- 直接使用提示词生成
- 确保设置 `aspect_ratio: 4:3`
