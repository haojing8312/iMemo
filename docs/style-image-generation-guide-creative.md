- **人物保留度**: 保持原始人脸特征不变
- **背景处理**: 彻底重构，与风格完美融合
- **艺术化程度**: 80-95% (高度艺术转换)
- **提示词语言**: 全部使用中文

### AI生成指令模板
```
【保持人物】面部特征完全保留，表情动作自然
【重构背景】去除原始背景，根据风格重新生成
【艺术转换】应用[风格名称]的完整艺术风格
【细节增强】添加[具体细节描述]
【氛围营造】整体呈现[情感氛围]
【比例】3:4竖版/4:3横版/1:1方形
【生成数量】同时生成4张不同动作/表情变体
```
